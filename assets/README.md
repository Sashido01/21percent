# Визуальные материалы

Графика создана для оформления репозитория. Она не объявляется официальной символикой Школы 21.

- [Hero](brand/hero.svg) — обложка.
- [Atlas](brand/atlas.svg) — карта направлений.
- [Signature](brand/signature.svg) — подпись.
- [Mark](brand/mark.svg) — знак для аватара или иконки.

См. [руководство по визуальной системе](../docs/DESIGN.md). Все изображения векторные и автономные, без внешних шрифтов, изображений или скриптов. Условия повторного использования см. в [правилах публикации](../docs/PUBLISHING.md).
