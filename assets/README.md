# SIGNAL ROOM / Графика

Авторская векторная айдентика публичного репозитория, не официальная символика Школы 21.

- [Обложка](brand/hero.svg) — исследовательская сфера, орбиты, абстрактная топография; статическая композиция.
- [Motion](brand/signal-motion.gif) — покадровая графика, 40 кадров по 120 мс, один проход. Воспроизводимый генератор: `node scripts/build_signal_motion.mjs` из корня.
- [Исследования](brand/research.svg), [практикум](brand/practice.svg), [эксперименты](brand/experiments.svg), [сообщество](brand/community.svg) — навигационные модули.
- [Карта](brand/atlas.svg) — дополнительная схема четырёх направлений.
- [Манифест](brand/signature.svg) и [знак](brand/mark.svg) — завершающая панель и аватар.

Все SVG автономны; графика условная и не отображает рыночные данные. См. [визуальную систему](../docs/DESIGN.md) и [правила публикации](../docs/PUBLISHING.md).

- [Portal entry](brand/portal-entry.svg) — вход в интерактивный портал.

- [Social preview](../docs/portal/social-preview.png) — фирменная обложка 1280×640 для ссылок и настройки GitHub Social preview; воспроизводится `node scripts/build_social_preview.mjs`.
