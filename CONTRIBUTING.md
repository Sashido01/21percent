# Как стать частью клуба

Не обязательно быть экспертом. Можно прийти с вопросом, проверить источник, предложить тему, подготовить учебный кейс или взяться за совместный проект.

## Как внести вклад

1. Проверьте, нет ли похожей идеи в Issues и каталоге.
2. Создайте Issue: проблема, польза, предложение и критерий готовности.
3. Для материала подготовьте черновик по соответствующему шаблону; для изменений в репозитории — pull request с понятным описанием.
4. Укажите источники, расчёты, ограничения и статус. Уберите персональные данные.
5. После обсуждения и проверки изменение может быть принято.

Уважайте [правила общения](CODE_OF_CONDUCT.md) и [редакционную политику](docs/PUBLISHING.md). Не добавляйте материалы, если не имеете права их публиковать.
