# История изменений

## 0.0.6 — 2026-11-25

- Зафиксирована успешная публикация Pages версии 0.0.5, добавлен прямой вход в портал из README.
- Добавлен отдельный HTTP smoke test: HTTPS, MIME, шесть публичных ресурсов, версия и проверка совпадения файлов после развёртывания main.
- Анимация изначально приостановлена до инициализации JavaScript, чтобы при его отключении не было неконтролируемого движения.
- Визуальная приёмка владельцем не подменяется проверками CI.

## 0.0.5 — 2026-11-25

- Уровень 2: статический адаптивный портал SIGNAL ROOM с интерактивной картой направлений, управлением движением, библиотекой с поиском и фильтрами, двумя калькуляторами и каталогом инициатив.
- Формулы и контент отделены от интерфейса; добавлены модульные и браузерные проверки.
- Подготовлена публикация через GitHub Pages из main:/docs. Само включение Pages и проверка публичного адреса остаются отдельной задачей владельца.

## 0.0.4 — 2026-11-25

- SVG-движение заменено настоящей покадровой GIF-анимацией; добавлен воспроизводимый генератор.
- Добавлены четыре нативные раскрывающиеся панели, включая учебную задачу с тремя раскрываемыми ответами.
- Расширен CI: контроль воспроизводимости и независимая структурная проверка GIF.
- Уровень 2 не изменён.

## 0.0.3 — 2026-11-25

- SIGNAL ROOM, уровень 1: новая обложка с однократной анимацией, четыре самостоятельных навигационных модуля и новый манифест.
- Главная страница перестроена вокруг быстрых сценариев участия, ссылки на реальные GitHub Discussions и статус CI.
- Обновлены визуальная система и правила агента; расширены проверки HTML-ссылок и доступности SVG.
- GitHub Pages не затронут: уровень 2 запланирован отдельно после приёмки.

## 0.0.2 — 2026-11-25

- Добавлена автономная проверка обязательных файлов, внутренних ссылок, SVG и версионности.
- Добавлен GitHub Actions workflow с доступом только на чтение.
- Фактический результат CI проверяется отдельно в Actions.

## 0.0.1 — 2026-11-25

- Создана публичная структура клуба, навигация и авторский SVG-комплект CAPITAL LAB.
- Добавлены миссия, направления, дорожная карта, каталог инициатив и границы 21% INVEST.
- Добавлены методика исследований, шаблоны встреч и два учебных кейса.
- Добавлены правила публикации, вклада, общения, безопасности и версионности.
- Добавлены шаблоны GitHub Issues и pull request.
- Это версия содержимого; наличие Git-тега и релиза следует проверять отдельно.

## 0.0.0 — 2026-11-25

- Инициализирован репозиторий.
