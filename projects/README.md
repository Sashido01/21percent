# Каталог инициатив

Здесь различаются реально проводившиеся форматы, разработки и идеи. Это не перечень завершённых продуктов.

| Инициатива | Статус | Суть |
| :--- | :--- | :--- |
| [21% INVEST](INVEST.md) | Практика обсуждений | Образовательное наблюдение за личным инвестиционным экспериментом. |
| FinPlay | Разработка / прототип | Многопользовательский игровой образовательный формат. |
| CASH404 | Разработка | Интерактивный финансовый детектив. |
| Аукцион знаний | Идея | Игровой обмен знаниями и обсуждение финансовых вопросов. |
| MoneyHub | Идея | Направление совместного финансового технологического проекта. |
| Налоговый калькулятор | Идея | Инструмент учебных расчётов с проверяемыми правилами. |

Проведение отдельных игровых форматов на встречах и выпуск их готовых публичных версий не подтверждены. Исходный код перечисленных разработок здесь не размещён.
