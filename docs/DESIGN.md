# SIGNAL ROOM / Визуальная система

SIGNAL ROOM — название дизайн-концепции, не переименование клуба. Уровень 1 — README в нативном интерфейсе GitHub. Уровень 2 — отдельный портал: исходники реализованы, Pages развёрнут; визуальная приёмка отдельно.

## Визуальные принципы

- Центральный образ: исследовательская сфера, сигнальные орбиты, контурный рельеф; не финансовые графики, не реальные измерения.
- Один крупный идентификатор 21%, ясный заголовок на русском, сдержанный лаймовый акцент. Карточки имеют заданную ширину 360 CSS px вместо 49%: на узком экране переносятся; нативные текстовые ссылки остаются запасным способом навигации.
- Самостоятельные карточки: контурная топография, объёмные модули, орбиты и сеть участников; единая геометрия, но разный рисунок.
- Интерактивность README — кликабельные навигационные карточки, нативные details/summary, четыре сценария участия и учебная задача с раскрываемой обратной связью. Ссылка на версию и штатный статус CI, а не нарисованные показатели.
- Главная мысль, навигация и описания продублированы в читаемом Markdown. Нет зависимости от цвета, анимации или изображения.
- Публичная графика автономна: без JS, внешних шрифтов, внешних ресурсов или встроенных обработчиков. Размеры изображений заданы, локальные SVG адаптируются по ширине README. На узких экранах текстовые ссылки остаются основным запасным способом навигации.
- Обложка статична и кликабельна; выделенный вход в портал находится сразу под ней. Motion-лента помещена в раскрываемый блок, чтобы не конкурировать с главным действием. Motion-лента — GIF с 40 кадрами по 120 мс, 4,8 секунды, без повторения; в ней нет значимой информации, доступной только в движении. GitHub управляет автовоспроизведением через настройки доступности. SVG-анимация не используется как зависимость от неподтверждённого поведения GitHub.

## Уровень 2 / портал

Портал переносит визуальный язык SIGNAL ROOM в HTML/CSS: крупная типографика, орбитальная карта с реальными ссылками, адаптивные сетки, поиск, фильтры, интерактивные вычисления. Четыре узла ядра выбирают направление, подсвечивают траекторию и обновляют карточку предварительного просмотра с отдельным переходом; без JavaScript остаются обычными ссылками. Активный раздел отмечен в верхней навигации. Границы управляющих элементов используют усиленный контраст. Движение управляется кнопкой и системной настройкой reduced motion. Цветовые акценты сопровождаются текстом; предусмотрены видимый фокус, семантические секции, подписи полей и сообщения об ошибках. Внешние шрифты, трекеры, платные API и вымышленные данные не используются. Диаграммы расчётов используют общую шкалу внутри каждого сравнения, текстовые значения и пропорциональные полосы. Цвет не является единственным носителем результата; неверный ввод скрывает устаревшую диаграмму. Быстрые сценарии для доходности изменяют реальные поля формы. Подробности: [портал](PORTAL.md).

## QA и границы

Автоматические проверки: валидный XML, заголовок и описание новых SVG, запрет активного содержимого, размер файлов, локальные ссылки Markdown и HTML, версии. Отдельно необходима визуальная проверка реального рендера GitHub в светлой/тёмной теме и на узком экране; автовоспроизведение GIF зависит от настроек GitHub и браузера. Макет не является гарантией отображения пиксель в пиксель и не доказывает соответствие WCAG целиком.
