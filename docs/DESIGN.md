# SIGNAL ROOM / Визуальная система

SIGNAL ROOM — название дизайн-концепции, не переименование клуба. Уровень 1 — README в нативном интерфейсе GitHub. Уровень 2 — отдельный портал, пока запланирован.

## Визуальные принципы

- Центральный образ: исследовательская сфера, сигнальные орбиты, контурный рельеф; не финансовые графики, не реальные измерения.
- Один крупный идентификатор 21%, ясный заголовок на русском, сдержанный лаймовый акцент. Два визуальных столбца для навигации вместо мелких четырёх.
- Самостоятельные карточки: контурная топография, объёмные модули, орбиты и сеть участников; единая геометрия, но разный рисунок.
- Интерактивность README — обычные ссылки на реальное содержимое. Ссылка на версию и штатный статус CI, а не нарисованные показатели.
- Главная мысль, навигация и описания продублированы в читаемом Markdown. Нет зависимости от цвета, анимации или изображения.
- Публичная графика автономна: без JS, внешних шрифтов, внешних ресурсов или встроенных обработчиков. Размеры изображений заданы, локальные SVG адаптируются по ширине README. На узких экранах текстовые ссылки остаются основным запасным способом навигации.
- Анимация ограничена 3,6 с, одним проходом; не мерцает и не требует остановки. При prefers-reduced-motion она отключается. Без CSS или при ограничениях GitHub сохраняется статическая композиция.

## QA и границы

Автоматические проверки: валидный XML, заголовок и описание новых SVG, запрет активного содержимого, размер файлов, локальные ссылки Markdown и HTML, версии. Отдельно необходима визуальная проверка реального рендера GitHub в светлой/тёмной теме и на узком экране; поддержка CSS-анимации зависит от браузера и обработчика SVG GitHub. Макет не является гарантией отображения пиксель в пиксель и не доказывает соответствие WCAG целиком.
