Формула и ограничения

(1 + доходность / 100) / (1 + инфляция / 100) − 1. Инфляция выше −100%; доходность не ниже −100%. Без налогов, комиссий и дополнительных взносов; одинаковый период для ставок.

—
Восстановление и покрытие дефицита

Формула и ограничения

Остаток резерва / обязательные расходы. Срок восстановления = внеплановый расход / (доход − обязательные расходы), если разница положительная. При недостатке резерва показан дефицит. Нет универсальной рекомендации по размеру резерва.
