# Версионность

- Старт: 0.0.0 — инициализация.
- Каждое завершённое изменение — отдельная микроверсия и запись в CHANGELOG.
- Нумерация: 0.0.1 … 0.0.99 → 0.1.0; 0.99.99 → 1.0.0. Если крупная незавершённая задача пересекла границу, промежуточные микрошаги допускаются до фактического завершения; релизная граница фиксируется явно.
- Коммиты и релизные записи описывают смысл изменений на русском языке.
- Теги релизов: vX.Y.Z. Не передвигать опубликованные теги; при ошибке выпускать новую версию.
- VERSION и CHANGELOG должны совпадать с текущей версией. Наличие записи не заменяет фактическую проверку тега.
- Изменения проверять до интеграции; для последующих работ предпочтительны pull request и squash merge.
