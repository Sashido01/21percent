# SIGNAL ROOM / Публикация портала

Портал находится в `docs/index.html`; файлы в `docs/portal/`. Это статический сайт без внешних библиотек, серверной части, cookies и хранения введённых финансовых данных. Значения калькуляторов обрабатываются в браузере и не отправляются на сервер.

## Публикация GitHub Pages

Портал: [SIGNAL ROOM](https://sashido01.github.io/21percent/).

Владелец включил Pages: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /docs. GitHub зарегистрировал успешное развёртывание версии 0.0.5 ([журнал](https://github.com/Sashido01/21percent/actions/runs/45647914752)).

Публичная проверка выполняется отдельным workflow Public portal availability: на PR проверяется действующая публикация, после интеграции — версия и байтовое совпадение опубликованных ресурсов с main. Повторные попытки учитывают задержку развёртывания. Это проверка доступности и целостности, не SLA. Не добавляйте внешний адрес в About до успешного HTTP smoke test.

## Локальная проверка

Из корня: `python -m http.server 8000 --directory docs`, затем открыть `http://localhost:8000/`. ES modules требуют HTTP, открытие файла напрямую не является поддерживаемым способом.

Тесты:

- `node --test scripts/portal.test.mjs` — расчёты, поиск, исходные пути, версия.
- `python scripts/check_portal_browser.py` — требуется Chrome/Chromium; проверяются сценарии взаимодействия и отсутствие горизонтального переполнения при ширине 1280, 360 и 320 px.
- `python scripts/check_repository.py` — структура, ссылки, SVG и версия.
- `python scripts/check_public_portal.py --expect-current` — публичный HTTPS, MIME, согласованность версии и байтовое совпадение текущей публикации; необходим интернет.

Фактическую доступность проверяет публичный smoke test, визуальная приёмка владельцем остаётся отдельной задачей. Открытие материалов и участие происходят по ссылкам на существующий GitHub. Каталог не выдаёт идеи за готовые проекты; нет вымышленных метрик или событий.

[Исходная страница](index.html) · [Дизайн](DESIGN.md) · [Документация](README.md)

Для обновления встроенного чтения после изменения исходных материалов выполните `node scripts/build_portal_previews.mjs`. CI проверяет совпадение; публичная проверка включает новый модуль после публикации текущего main.

## Социальное превью

Портал содержит Open Graph и Twitter Card метаданные с абсолютным адресом PNG 1280×640. [Обложка](portal/social-preview.png) подходит и для ручной загрузки через Settings → General → Social preview. Отображение в Telegram/VK зависит от их парсеров и кэша; отдельно не подтверждено. Генерация и проверка: `node scripts/build_social_preview.mjs --check` и `python scripts/check_social_preview.py`.

## Визуальные регрессии

`python scripts/check_portal_visual.py --out visual-qa --baseline <commit>` формирует восемь скриншотов в Chromium и отчёт JSON; без базового коммита — только текущие изображения. CI сравнивает с базой PR/предыдущим main и прикладывает скриншоты как артефакт. Проверки не доказывают полное соответствие WCAG и не охватывают Safari/Firefox или рендеринг README на GitHub.

## Публичное исследование цифрового рубля

[Цифровой рубль](ruble/index.html) — самостоятельный материал с накопительным маршрутом, раскрытием цепочек и калькуляторами. Факты, выводы и сценарии разделены; источники перечислены на странице. Данные расчётов не сохраняются и не отправляются. Режим ведущего отсутствует. Проверка: `node --test scripts/ruble.test.mjs`; публичная проверка текущей версии включает три файла исследования.


## Единый каталог исследований и лента

Публичные исследования используют `researchPublications` в `portal/content.mjs`. У каждой записи есть дата публикации, адрес, формат interactive и статусы поиска по ЦБ, Хабру, Reddit. Каталог показывает все записи по дате; лента — максимум три последних. Верхняя навигация содержит только постоянные разделы. Библиотека сохраняет поиск по теме. Общий маршрут `portal/research-route.mjs` раскрывает главы и вложенные вопросы, сохраняет состояние и открывает прямые якоря. Для цифрового рубля 51 вопрос встроен в соответствующие главы, старый адрес FAQ перенаправляет в единую презентацию. Источники и методика — внутри материала. При отключённом JavaScript главы и вложенные ответы доступны через нативные раскрывающиеся блоки.

### Живое полотно исследования

Модуль `portal/research-route.mjs` строит маршрут «вступление → добавление узла → раскрытие звеньев → возврат → итог». `portal/research-canvas.css` обеспечивает пространственную карту и адаптивность. Все подробности и модели остаются в исходном HTML и перемещаются в активную панель без копирования и сброса значений. Поиск и старые прямые ссылки открывают соответствующий вопрос на карте. Не заменяйте презентацию статьёй; fallback без JavaScript остаётся доступным.

Единственный публичный маршрут исследования — ранее согласованная живая накопительная карта SIGNAL ROOM. Внутри каждого звена сначала показывайте крупную схему, график или модель и короткий вывод. Полный исходный текст, расчёты и источники раскрываются на том же этапе по кнопке; возможность открытия текста должна быть доступна на вступлении, карте, углублении, возврате и финале. Не создавайте отдельную презентацию для выступления или параллельный текстовый маршрут. Сохраняйте принятый дизайн, содержание и связи; все посетители используют один адрес.

Проверка 0.0.20: все 32 схемы сопоставлены с исходными звеньями по идентификаторам глав; шкала процентных диаграмм фиксирована на 100%, а окно библиотеки возвращает фокус сразу после закрытия. Ручная приёмка на проекторе не проведена.

Технический долг: PR №19 признан дублирующим PR №18 после сравнения реализаций. Автоочистка допускает удаление только точного SHA дублирующей ветки после закрытия PR, подтверждённого squash-слияния замены и успешного CI main. История PR сохраняется.

После squash исходный коммит не обязан находиться в локальном клоне main. Для явно зарегистрированной замены сверяется SHA Git-объекта и SHA дерева из GitHub Git API; исходная ветка не восстанавливается. При ошибке доказательства ветка сохраняется.

### Вступление цифрового рубля

Обложка задаёт практический вопрос. Анимированные орбиты и световые потоки работают только на вступлении; можно остановить движение, системное уменьшение движения отключает его автоматически. Кнопка «Начать исследование» открывает первую ветку той же карты. Полный текст вступления доступен через «Открыть текст».

Заголовок вступления «Ваши деньги. Чьи правила?» занимает две смысловые строки. Размер рассчитывается по доступной ширине; нижний блок о выгоде удалён. Полный текст, анимация и навигация сохранены.

Первое звено сравнивает три формы рубля в отдельных строках: что это, где находятся деньги и как ими платить. В раскрываемом тексте отдельно объяснены экономический смысл и классификация по статье 128 ГК РФ. Второе звено показывает перевод 1 000 ₽ между двумя остатками. Новая схема сохраняет прежний маршрут и доступ к источникам.

Во втором звене показаны два собственных счёта и неизменная общая сумма до и после перевода. Ссылки в пояснениях подчёркнуты, официальные инструкции по пополнению и обратному переводу выделены отдельными элементами. Автотесты проверяют адреса, оформление и адаптивность.

### Проверка вопросов и переходов 0.0.26

Просмотрены 32 звена и 51 вопрос. Устранены повтор краткого ответа, двусмысленное «нет» в вопросе об инфляции, рекомендации без перехода к модели, неясные ссылки и отдельные профессиональные термины. Ссылки на материалы ведут напрямую на адрес из реестра (новая вкладка), прямая ссылка открывает полный вопрос, а старые якоря источников открывают нужную запись в окне. Переход к модели раскрывает нужное звено. Источники обсуждения отделены от подтверждения ответа. Тесты сверяют URL с реестром и проверяют навигацию; это не подтверждает доступность всех внешних сайтов и актуальность всех фактов.
