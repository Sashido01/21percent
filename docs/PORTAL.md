# SIGNAL ROOM / Публикация портала

Портал находится в `docs/index.html`; файлы в `docs/portal/`. Это статический сайт без внешних библиотек, серверной части, cookies и хранения введённых финансовых данных. Значения калькуляторов обрабатываются в браузере и не отправляются на сервер.

## Подключить GitHub Pages

Владелец репозитория: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /docs → Save. Дождаться успешной публикации в интерфейсе GitHub и открыть URL, показанный на странице Pages. Только после проверки доступности добавлять публичную ссылку в README и About.

## Локальная проверка

Из корня: `python -m http.server 8000 --directory docs`, затем открыть `http://localhost:8000/`. ES modules требуют HTTP, открытие файла напрямую не является поддерживаемым способом.

Тесты:

- `node --test scripts/portal.test.mjs` — расчёты, поиск, исходные пути, версия.
- `python scripts/check_portal_browser.py` — требуется Chrome/Chromium; проверяются сценарии взаимодействия и отсутствие горизонтального переполнения при ширине 1280, 360 и 320 px.
- `python scripts/check_repository.py` — структура, ссылки, SVG и версия.

Фактическая доступность опубликованного сайта и визуальное качество проверяются отдельно после активации Pages. Открытие материалов и участие происходят по ссылкам на существующий GitHub. Каталог не выдаёт идеи за готовые проекты; нет вымышленных метрик или событий.
