## Проверка репозитория

Из корня Git-репозитория выполните:

```sh
python3 scripts/check_repository.py
```

На Windows при наличии Python Launcher: `py -3 scripts/check_repository.py`.

Проверка не требует сторонних библиотек или доступа к сети. Она проверяет только отслеживаемые Git файлы, наличие обязательных путей, внутренние ссылки на файлы, корректность SVG и согласованность версии с историей. Она не проверяет фактическую достоверность публикаций, внешние URL или визуальный рендеринг. Те же проверки предусмотрены в GitHub Actions.
