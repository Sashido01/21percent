# Встречи клуба

Клуб формируется с июня 2026 года. Очные встречи и финансовые обсуждения уже проводились. В истории также были обсуждения инвестиционных инструментов и голосования.

Подробные даты, число участников, фотографии и итоги не внесены без подтверждённых материалов и необходимых разрешений. Не считаем анонс состоявшейся встречей.

Для каждой новой записи используйте [шаблон](TEMPLATE.md). Форматы могут включать исследовательский разбор, практическую задачу, дискуссию, игру или совместный проект. Тема цифрового рубля рассматривается как тема встречи; факт её проведения отдельно не подтверждён.
